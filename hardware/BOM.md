# FIREGUARD AI — Bill of Materials

This document lists the hardware components planned for the FIREGUARD AI
prototype.

## Core Hardware

| Component | Quantity | Purpose | Status |
|---|---:|---|---|
| ESP32 development board | 1 | Sensor acquisition and communication | Planned |
| Raspberry Pi | 1 | Edge AI inference and local processing | Planned |
| Camera module / USB camera | 1 | Fire and smoke visual detection | Planned |
| DHT22 | 1 | Temperature and humidity monitoring | Planned |
| Smoke/gas sensor | 1 | Environmental anomaly detection | Planned |
| LED | 1 | Visual warning indicator | Planned |
| Buzzer | 1 | Local audible warning | Planned |
| Breadboard | 1 | Prototype circuit | Planned |
| Jumper wires | 1 set | Hardware connections | Planned |

## Software / Development Requirements

- Arduino IDE or PlatformIO
- Python
- OpenCV
- PyTorch
- Ultralytics YOLO
- FastAPI
- PostgreSQL
- React
- Git

## Notes

Component specifications may change during development based on
availability, compatibility, testing results, and system requirements.

Actual component models, costs, suppliers, and final quantities will be
recorded after the prototype hardware is finalized.
